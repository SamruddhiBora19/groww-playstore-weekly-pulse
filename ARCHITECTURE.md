# GROWW Play Store Review Weekly Pulse Generator
## Phase-Wise System Architecture & Technical Specification (Modular 5-Phase Stack)

---

## 1. Executive Summary & Problem Statement

**Product**: GROWW (Leading Investment & Financial Platform)  
**Goal**: Transform raw Play Store user reviews from the past 3 months into a concise, high-value **One-Page Weekly Pulse** using **Google Gemini LLM** via a **5-Phase Modular Architecture** (FastAPI Backend + Next.js Web UI Dashboard + Python CLI Tool).

### Key Deliverables
- **Phase-Wise Modular Directory Architecture**: Self-contained folders for each phase (`phase1_ingestion`, `phase2_llm_intelligence`, `phase3_web_dashboard`, `phase4_email_dispatcher`, `phase5_nextjs_frontend`).
- **Phase 5 Next.js Web UI Dashboard**: Modern Next.js React Dashboard interface to trigger review fetching, run LLM analysis, view the 1-page pulse, preview HTML drafts, and dispatch personalized emails.
- **Unified Python CLI (`cli.py`)**: Multi-command CLI tool to generate pulses, dispatch emails, or run backend/frontend servers.
- **Theme Discovery**: Group reviews into 3 – 5 core themes max generated by Google Gemini LLM.
- **Weekly Pulse Content**:
  - **Top 3-5 Themes** (with percentage weightage, sentiment split, key drivers).
  - **3 Verbatim User Quotes** (representative user feedback, zero PII).
  - **3 Action Ideas** (tailored for Product/Growth, Support, and Leadership teams).
- **Interactive Email Dispatcher**: Personalization controls (`Hi {recipientName},`) in web app & CLI to dispatch HTML emails directly to any target recipient via Gmail SMTP (`smtplib`).
- **Execution Model**: Strictly **On-Demand & User-Triggered** (No background schedulers, cron jobs, or automatic timers). System executes review fetching, LLM synthesis, and email dispatch solely upon explicit user action via the Next.js Web UI or Python CLI.
- **PII Compliance**: Strict scrubbing of all personal identifiable information before LLM ingestion.

## 4. How to Run Each Phase & CLI Commands

### Unified CLI Command Center (`python cli.py`)

```bash
# 1. Generate Weekly Pulse directly in CLI terminal
python cli.py pulse --weeks 12

# 2. Dispatch personalized Weekly Pulse email via CLI
python cli.py email --to user@example.com --name "Samruddhi"

# 3. Start FastAPI Backend API Server (Port 8000)
python cli.py serve

# 4. Start Phase 5 Next.js Web UI Dev Server (Port 3000)
python cli.py web

# 5. Start Streamlit Web Dashboard (Port 8501)
python cli.py streamlit
```

### Phase-Wise Standalone Execution

```bash
# Phase 1: Standalone Ingestion & PII Redaction
python -m phase1_ingestion.run_phase1

# Phase 2: Standalone Gemini LLM Pulse Generation
python -m phase2_llm_intelligence.run_phase2

# Phase 4: Standalone Email Dispatcher
python -m phase4_email_dispatcher.run_phase4 user@example.com "Samruddhi"

# Phase 5: Next.js Web UI Manual Launch
cd phase5_nextjs_frontend && npm run dev

# Streamlit Direct Launch
streamlit run streamlit_app.py
```

## 5. Streamlit Deployment Guide

Deploying the GROWW Weekly Pulse Generator on **Streamlit Community Cloud** (or any Streamlit host) requires **zero Node.js or FastAPI server configuration**:

1. **Repository Files**:
   - Primary Entrypoint: `streamlit_app.py`
   - Dependency Manifest: `requirements.txt` (includes `streamlit>=1.32.0`)
2. **Secrets Configuration (`.streamlit/secrets.toml`)**:
   Add your Gemini API key and optional SMTP credentials in Streamlit Cloud Secrets:
   ```toml
   GEMINI_API_KEY = "your_gemini_api_key"
   GROQ_API_KEY = "your_groq_api_key"
   SMTP_HOST = "smtp.gmail.com"
   SMTP_PORT = "587"
   SMTP_USER = "your_email@gmail.com"
   SMTP_PASS = "your_app_password"
   ```
3. **Deployment Steps on Streamlit Community Cloud**:
   - Push codebase to GitHub.
   - Go to [share.streamlit.io](https://share.streamlit.io) -> **New app**.
   - Select repository, set **Main file path** to `streamlit_app.py`.
   - Paste environment secrets in **Advanced settings -> Secrets**.
   - Click **Deploy!**
